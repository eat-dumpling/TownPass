# PRD — 台北通本地端 AI 城市服務助理（PoC）

## 1. 問題與價值

市民尤其長者不一定知道正確的市政服務名稱，也不一定有穩定行動網路。現有 FAQ / 資料集對自然語言查詢不夠友善。此 PoC 用離線搜尋 + 可選本機生成，把**已下載且可驗證的官方公開資訊**整理成容易理解的繁體中文回答。

### 主要故事

- 作為長輩，我可以輸入「文山區哪裡可以找社區關懷據點」，得到資料列表及來源，而不是一堆 AI 猜測。
- 作為網路不穩定的市民，我可以在關閉網路後搜尋手機上已有的服務資料。
- 作為注重隱私的使用者，我可以不用登入、不傳送問題就查詢。
- 作為舊裝置使用者，我不想被強迫下載 1GB 模型才可查詢基本服務。

## 2. P0 範圍

### F-01 啟動畫面

- 標明「本地端 AI 功能示範／非臺北市正式服務」。
- 啟動時直接可用「離線檢索」。
- 顯示「資料更新時間」及「已下載 X 筆資料」；資料時間未知則顯示未知，不假造日期。
- 顯示網路狀態「連線/離線」僅作參考，不作搜尋啟用門檻。

### F-02 中文查詢

- 提供輸入框、常見問題 chip（測試用問題須標明示範）。
- 檢索結果顯示標題、摘要、區域、資料日期、資料源網址。
- 提供「檢視原始資料」外部連結，打開前檢查 URL 為 https 且在允許來源中。
- 低信心或無答案時顯示：`目前離線資料不足，無法確認；請查詢官方最新資訊。`
- 不應生成或顯示未來活動日期、報名餘額、資格、費用，除非實際資料包含這些欄位且已標明時效。

### F-03 本機生成式 AI（使用者選擇啟用）

- 預設關閉。說明約略下載量、儲存與耗電成本。
- 顯示已安裝模型來源與版本、模型是否下載完、校驗狀態。
- 本機引擎串流回答，按停止可取消。
- 生成文字下方**必須**顯示檢索引用卡片；任何 AI 文字連結應透過引用卡資料來源確認，不直接信任模型產出的 URL。
- 若模型不能執行或設備資源不足，立即轉回離線檢索；不能改呼叫雲端 API。

### F-04 公開資料更新

- 只在使用者按更新後發送請求（第一版不做背景輪詢）。
- 在畫面明確顯示下載大小、資料來源、是否更新成功。
- 離線或伺服器故障保留舊資料，並顯示目前版本。

### F-05 模型管理

- 可下載、取消、刪除模型。
- Google Gemma 3 1B IT 僅在來源授權與合法下載端點完成配置後可啟用。
- SmolLM2 135M 只用於 smoke test，UI 標明繁體中文品質不代表可上線。

## 3. UX / A11y

- 全繁體中文（臺灣用語）；避免「你需要懂 AI」的技術文案。
- 可由使用者自由調整文字大小；支援 Android TalkBack 與 iOS VoiceOver 的按鈕語意。
- 所有關鍵狀態以文字顯示，不僅用顏色；觸控區域盡量至少 44×44 logical pixels。
- 生成結果與引用來源分區，不將來源偽裝成 AI 的確定陳述。
- 「無網路仍可查已下載資料」需要可實際測試。

## 4. 非功能需求與安全

- 不依賴臺北通帳號、不要求敏感權限、不蒐集個資。
- 採單一背景資料更新流程，避免更新與讀取競態；原子更新/回滾。
- 離線搜尋應在低階手機可用；超出記憶體或 OS 最低版本的手機，不強行啟用 LLM。
- 可觀察但不得洩漏聊天內容：本機可顯示 RAM 估計、模型大小、生成總時間；預設不回傳 analytics。
- 對資料/模型設大小與完整性檢查，防止磁碟耗盡或損壞檔載入。

## 5. 衡量指標（實測前是驗收目標，不是已有成績）

| KPI | 目標 / 量測 |
|---|---|
| 離線檢索 | 100% 受控測試案例在無網路通過 |
| 資料可追溯 | 100% 結果顯示來源、能取得的資料日期 |
| 生成隱私 | 測試中 0 個 prompt/response 上傳請求 |
| 結果可信度 | 不以模型生成的 URL 作為可信來源 |
| 語意品質 | 先人工建立 20 個台灣繁體中文問題，標記 grounded / insufficient；不杜撰 |
| 推論效能 | 真機記錄峰值 RAM、首 token 延遲、token/s、電量、過熱；尚無通用達標保證 |

## 6. 非目標

正式臺北通單一登入、金融/福利申請、個人醫療紀錄、健保卡、診斷、社交配對、實時活動報名、語音、多模態、全臺地圖。這些絕不能假裝已完成。
