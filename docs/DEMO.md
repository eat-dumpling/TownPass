# Demo 腳本：初選 2 分鐘、決選 5 分鐘

規則：只能實機操作，不用簡報。一位講、一位操作手機（投影）。

**一句話（兩次都用這句開場、這句收尾）**
> 垃圾怎麼丟，拍一下、用你的語言、一步一步告訴你。

**固定道具**：手搖飲料杯（主角）、寶特瓶（備用）。都是 verified、辨識信心高的品項。

**上台前 10 分鐘**
- 台北通已登入，丟丟放在「我的服務」第一格（手機可開飛航模式以防場地網路不穩，但不當亮點講）。
- 先進一次丟丟的拍照、兒童模式的掃一掃，讓模型載入（預熱）。
- 丟丟語言先切成越南文＋中文對照。
- 備援：拍照失手時改「用名字找」；整台當掉時播備援影片。

## 初選：2 分鐘（逐桌，評審站在旁邊看手機）

目標：讓評審記住**一句話＋一個畫面**，不展示功能清單。

| 時間 | 講什麼 | 手機上做什麼 |
|---|---|---|
| 0:00–0:15 | 「臺北的垃圾規則寫得很清楚，但前提是看得懂中文。我們做的是：垃圾怎麼丟，拍一下、用你的語言、一步一步告訴你。」 | 停在台北通首頁 |
| 0:15–0:30 | 「阿蘭是越南新住民媽媽，晚上 9 點手上有一杯喝完的手搖杯。」 | 點「我的服務」→ 丟丟（已是越南文＋中文） |
| 0:30–1:10 | 「她不用打字，拍一下就認出來。答案不是 AI 編的，是查環保局的官方規則表。」 | 拍手搖杯 → 結果：倒空、沖一下、撕封膜，三張圖卡 |
| 1:10–1:25 | 「她也知道今天收不收、要交給哪一台車。」 | 點「今天」：今天收什麼／垃圾車時間 |
| 1:25–1:45 | 「同一套規則，孩子也看得懂：每個字都有注音，拖進對的桶就拿到星星。」 | 結果卡右上「兒童模式」→ 掃一掃同一個杯子 → 拖進綠色桶 → 星星 |
| 1:45–2:00 | 「同一張卡，一鍵換成印尼文、泰文——一套官方規則，大人、孩子、八種語言都看得懂，而且每條規則都對過環保局資料。」 | 結果卡右上「中文」鈕 → 印尼文 → 泰文（卡片當場重畫） |

**不講**：語音助理、地圖、提醒設定、蓋里、等級、準確率數字。

## 決選：5 分鐘＋問答（上台投影）

目標：情境完整（25）、能落地（30）、穩定（20）。比初選多講「誰接手、資料怎麼來、為什麼不會講錯」。

| 時間 | 段落 | 講什麼 | 手機上做什麼 |
|---|---|---|---|
| 0:00–0:30 | 痛點 | 「臺北有數萬名外籍居民與新住民、十幾萬名國小學童（上台前用內政部移民署與教育局統計查證數字）。規則只有中文、名詞抽象（立體類、平面類），看不懂就丟錯、被罰、或乾脆不敢丟。」 | 台北通首頁 |
| 0:30–2:00 | 主流程：阿蘭 | 同初選：進丟丟 → 拍手搖杯 → 三步圖卡 → 今天收什麼、垃圾車幾點 → **設到站提醒**（本機通知，用台北通原生能力） | 拍照 → 圖卡 → 今天 → 收藏停靠點／提醒 |
| 2:00–2:30 | 現場溝通 | 「在垃圾車旁邊想問清潔隊員，可以秀這張中文＋母語對照卡。」 | 打開溝通卡（只停 10 秒） |
| 2:30–3:20 | 兒童模式 | 「孩子在家幫忙分類：注音、圖像、拖進桶，對了拿星星；考考你的題目也是從同一份規則表產生的。」 | 兒童模式 → 掃一掃 → 拖進桶 → 星星 → 回丟丟 |
| 3:20–4:10 | 為什麼不會講錯 | 「模型只負責認出是什麼東西，答案只查規則表。107 條規則逐條對過回收一點通與 data.taipei，84 條核對過的才上線；官方說法不一致的，畫面會說請洽清潔隊。沒把握就不回答，改成讓你從圖卡選。」 | 品項卡底部的來源小字 |
| 4:10–4:45 | 能落地 | 「頁面和模型都內建在 App，不用伺服器、沒有雲端 AI 費用。資料由環保局每季核對規則表、開放資料重跑腳本更新；我們是回收一點通的多語與兒童前端，不是另一套系統——今天就能接。」 | 品項卡底部的來源小字 |
| 4:45–5:00 | 收尾 | 「同一個杯子：阿蘭看越南文、孩子看注音、阿嬤看圖卡。垃圾怎麼丟，拍一下、用你的語言、一步一步告訴你。」 | 結果卡右上語言鈕切回中文，停在三張圖卡上 |

## 問答：預備答案

| 問題 | 答案要點 |
|---|---|
| 跟回收一點通、環保局 App 重複嗎？ | 資料同源，我們是前端：不用打中文關鍵字，拍照或說母語就能問，一次一步帶著做；孩子用注音學 |
| 辨識錯了、孩子學錯誰負責？ | 答案只來自規則表；只有核對過的 84 條上線；信心不夠就不回答、改用選的；規則由環保局核對 `status` |
| 關掉網路還能用嗎？ | 可以，當場開飛航模式給評審看；辨識、規則、收運時間都在手機上；只有地圖底圖要網路，斷網時自動改成停靠點清單 |
| 用了什麼 AI？ | Google SigLIP（q8 ONNX）認東西、MediaPipe EfficientDet-Lite0 框物品，都在 WebView 內推論，Apache-2.0；沒有生成式 AI |
| 翻譯可信嗎？ | 規則名詞以環保局官方英文為準；越、印等語言下一步請新住民服務中心與移工團體校稿 |
| 個資？ | 不用帳號；相機畫面不上傳不存檔；位置用完即丟，只存停靠點編號與里名 |
| App 變大多少？ | 約 100 MB 模型，兩個模式共用一份；可改成首次使用時下載 |
| 上線後誰維護？ | 資料：環保局開放資料自動重抓；規則表：環保局每季核對；程式：AGPL 開源，資訊局接手 |
