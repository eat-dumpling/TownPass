# Demo 腳本：初選 2 分鐘、決選 5 分鐘

規則：只能實機操作，不用簡報。一位講、一位操作手機（投影）。
本版依 2026-11-08 的 `develop`（丟丟首頁「今天要丟什麼？」、底部只有「首頁／附近」，拍照是首頁的大按鈕）逐步走過；標「實機」的步驟要在上台前用 iPhone 再走一次。

**一句話（兩次都用這句開場、這句收尾）**
> 垃圾怎麼丟，拍一下、用你的語言、一步一步告訴你。

**固定道具**：手搖飲料杯（主角）、寶特瓶（備用，README 主圖就是實機框出寶特瓶 62%）。

## 上台前 10 分鐘（照順序做）

1. **裝最新版**：iPhone 上是最新的 `develop`，打開一次確認首頁出現。
2. **語言**：丟丟首頁右上「中文」→ 上面選「繁體中文」，下面「對照語言」選「Tiếng Việt」。全頁變成中文大字＋越南文小字。（越南文在 iPhone 上顯示正常；電腦 Chrome 的聲調位置會跑掉，不要用電腦投影。）
3. **先設定好垃圾車**：首頁「還沒設定你的垃圾車 › 更改」→「或選擇你的里」選家附近的里 → 選一個停靠點 → 下一步 →「沒有，我自己追垃圾車」→ 開始丟垃圾。設好後首頁會顯示「明天 17:20 某某路」這一列，台上按「我要丟棄」才會直接進清單，不會跳出設定頁。
4. **清掉上次的勾選**：首頁「這些東西要怎麼丟」→ 下方「全部取消」。
5. **預熱模型**：按首頁大按鈕「拍一件垃圾」（開了對照語言要往下滑一點），等到「準備辨識… 100%」、對著杯子出現框，再按左上 ✕ 回首頁。兒童模式的「掃一掃」也進一次。
6. **權限**：相機、定位、通知都已允許（第一次會跳系統詢問，不要留到台上）。
7. **備援**：拍照失手 → 相機頁左下「手動選擇」→ 手搖飲杯；整台當掉 → 播備援影片。

**今天是週日（停收日）**：首頁大卡片會寫「今天停收／明天 一般、廚餘、平面類」，清單的出門時間是「明天」。照實講，這正好說明「看不懂規則」的痛點。

## 初選：2 分鐘（逐桌，評審站在旁邊看手機）

目標：讓評審記住**一句話＋一個畫面**，不展示功能清單。

| 時間 | 講什麼 | 手機上做什麼 |
|---|---|---|
| 0:00–0:15 | 「臺北的垃圾規則寫得很清楚，但前提是看得懂中文。我們做的是：垃圾怎麼丟，拍一下、用你的語言、一步一步告訴你。」 | 台北通首頁 |
| 0:15–0:30 | 「阿蘭是越南新住民媽媽，手上有一杯喝完的手搖杯。今天週日，她也不知道今天收不收。」 | 底部「服務」→ 我的服務「丟丟」→ 首頁「今天停收／明天…」（中越對照） |
| 0:30–1:05 | 「她不用打字，拍一下就認出來。答案不是 AI 編的，是查環保局的規則表。」 | 首頁大按鈕「拍一件垃圾」→ 對杯子 → 點框或下方卡片「手搖飲料杯」→ 怎麼丟：倒掉飲料、撕膜抽吸管、倒空沖洗 |
| 1:05–1:30 | 「按我要丟棄，幫她排好：袋子、先處理、明天幾點到哪裡交。到了車旁邊，還有中越對照的溝通卡。」 | 「我要丟棄」→ 清單已勾杯子 →「看怎麼丟」→ 3 出門丟「明天 17:20」→「給隊員看」 |
| 1:30–1:50 | 「同一套規則，孩子也看得懂：每個字都有注音，拖進對的桶就拿到星星。」 | 返回丟丟首頁 → 右上「兒童模式」（轉圈約 2 秒）→ 掃一掃（或「用選的」→ 喝的 → 手搖飲料杯）→ 拖進綠色「資源回收」→ 做對了 |
| 1:50–2:00 | 「一套官方規則，大人、孩子、八種語言都看得懂。」 | 停在「做對了」畫面 |

**不講**：語音助理、地圖、提醒設定、蓋房子、準確率數字。

## 決選：5 分鐘＋問答（上台投影）

目標：情境完整、能落地、穩定。比初選多講「誰接手、資料怎麼來、為什麼不會講錯」。

| 時間 | 段落 | 講什麼 | 手機上做什麼 |
|---|---|---|---|
| 0:00–0:30 | 痛點 | 「臺北有數萬名外籍居民與新住民、十幾萬名國小學童（上台前用移民署與教育局統計查證數字）。規則只有中文、名詞抽象（立體類、平面類），看不懂就丟錯、被罰、或乾脆不敢丟。」 | 台北通首頁 |
| 0:30–0:50 | 進入 | 「入口就在台北通的服務裡。今天週日停收，丟丟直接告訴她明天收哪幾類。」 | 服務 → 丟丟 → 首頁「今天停收」卡（中越對照） |
| 0:50–1:40 | 拍照 | 「拍一下，畫面裡每件東西都有框；辨識在手機上做，不上傳。答案查規則表：手搖杯是立體類、星期二四六回收，封膜和吸管是一般垃圾。」 | 首頁往下滑一點，大按鈕「拍一件垃圾」→ 杯子出框 → 點卡片 → 怎麼丟卡（三步＋黃色提醒） |
| 1:40–2:40 | 排步驟 | 「她按我要丟棄，還可以把寶特瓶一起勾進來。丟丟排好：用一般袋子、先處理、明天 17:20 在哪一站交。珍珠要倒進車後的廚餘桶。提醒用台北通原生的本機通知，車到前通知她。」 | 「我要丟棄」→ 再勾「寶特瓶」→「看怎麼丟」→ 出門丟卡 →「提醒我」→ 往下看「車來了，交出去：廚餘桶、回收車」 |
| 2:40–3:00 | 現場溝通 | 「到了車旁邊，把這張中越對照卡給清潔隊員看。」 | 「給隊員看」→ 停 10 秒 |
| 3:00–3:30 | 語音（場地太吵就跳過） | 「不會打中文也可以用說的。」 | 返回首頁 →「問我怎麼丟」→ 點範例「舊衣回收箱在哪？」→ 地圖框出最近的回收箱 →「知道了」 |
| 3:30–4:15 | 兒童模式 | 「孩子在家幫忙分類：注音、圖像、拖進桶，對了拿星星；題目也是從同一份規則表產生的。」 | 首頁 →「兒童模式」（轉圈約 2 秒）→ 掃一掃同一個杯子 → 送它回家 → 拖進「資源回收」→ 做對了 →「看分辨卡 ★+1」→ 右上箭頭回丟丟 |
| 4:15–4:45 | 為什麼不會講錯、能落地 | 「模型只負責認出是什麼東西，答案只查規則表。107 條規則逐條對過回收一點通與 data.taipei，84 條核對過的才上線；官方說法不一致的會說請洽清潔隊；沒把握就不回答，改成讓你自己選。頁面和模型都內建在 App，不用伺服器、沒有雲端 AI 費用；資料由環保局開放資料重跑腳本更新。」 | 停在丟丟首頁（不要在這段操作） |
| 4:45–5:00 | 收尾 | 「同一個杯子：阿蘭看越南文、孩子看注音、阿嬤看圖卡。垃圾怎麼丟，拍一下、用你的語言、一步一步告訴你。」 | 停在首頁 |

**時間不夠時先砍**：語音（3:00–3:30）→ 寶特瓶那一下 → 分辨卡。

**通知要現場秀的話（選用）**：上台前 1 分鐘，丟丟首頁點「今天停收」卡 → 最下面「傳送 1 分鐘後的測試通知」，通知會在「排步驟」那段跳出來。

## 問答：預備答案

| 問題 | 答案要點 |
|---|---|
| 卡片寫手搖杯「星期二、四、六回收」，清單卻叫她星期一拿出去？ | 立體類建議二四六；環保局 FAQ 說其他收運日回收車也收，所以清單排最近的一班。 |
| 跟回收一點通、環保局 App 重複嗎？ | 資料同源，我們是前端：不用打中文關鍵字，拍照或說母語就能問，一次一步帶著做；孩子用注音學。 |
| 辨識錯了、孩子學錯誰負責？ | 答案只來自規則表；只有核對過的 84 條上線；信心不夠就列候選讓人選；規則由環保局核對 `status`。 |
| 關掉網路還能用嗎？ | 可以：辨識、規則、收運時間都在手機上；只有地圖底圖要網路，斷網時改成停靠點清單。 |
| 用了什麼 AI？ | Google SigLIP（q8 ONNX）認東西、MediaPipe EfficientDet-Lite0 框物品，都在 WebView 內推論，Apache-2.0；沒有生成式 AI。 |
| 翻譯可信嗎？ | 規則名詞以環保局官方英文為準；越、印等語言是機器輔助翻譯，下一步請新住民服務中心與移工團體校稿。 |
| 個資？ | 不用帳號；相機畫面不上傳不存檔；位置用完即丟，只存停靠點編號與里名。 |
| App 變大多少？ | 約 100 MB 模型，兩個模式共用一份；可改成首次使用時下載。 |
| 上線後誰維護？ | 資料：環保局開放資料重抓；規則表：環保局每季核對；程式：AGPL 開源，資訊局接手。 |
