# 城市小幫手的大字與簡潔介面

目標是讓使用者先完成「直接打字提問 → 閱讀本機回答 → 有來源時展開核對」。原城市通首頁與導覽保留；小幫手仍是本機 WebView 微服務，實際推論由 native llamadart 處理。

主畫面使用暖白底、深色青綠文字、20px 基準字級與至少 56px 的按鈕。小對話符號以本機 CSS 畫成，不增加外部圖檔或下載。快捷選項先呈現「認識你」、「找美食」；市政行政區收進「查詢市政資料」展開區；不要求定位。輸入與送出固定下方，避免長回答讓下一題輸入框離開畫面。短視窗收起非必要的輸入區標題，保留輸入及送出。

模型、SHA、授權與公開資料更新都收進設定視窗；原生下載確認仍說明來源、大小與授權。已安裝模型會自動使用，主畫面不需要開啟按鈕。載入中仍可送出，畫面表示問題已保留並可停止，完成後自動回答；只有缺少模型才顯示下載入口。設定可改用省電查詢、重試 AI 或額外放大字級 25%，沒有持久保存對話或字級。

回答與來源分開。一般回答標示「手機 AI 對話」及「未連線查證」；有參考資料時標示「手機 AI・資料參考」並附來源；純檢索標示「查詢結果」。來源先顯示標題、地址、電話與資料日期；完整原文／網址與其餘來源由使用者展開。來源 URI 始終由 native 以驗證過的 document ID 開啟。

前端只改變有變化的回答文字，並保留未改變的來源節點，減少串流時對讀屏與焦點的干擾。新對話需收到 native 清除確認才重新開放輸入；對應 request ID 的失敗會復原送出功能。資料成功更新會清除舊引用，取消或失敗則保留。

已驗證：前端 Node 狀態測試、Flutter 單元／Widget、兩平台模擬器 native 對話流程、系統 200% 字級與水平溢出檢查；iOS 另外驗證回到 100% 字級。原生截圖見 artifacts/validation。這些不是長者使用者研究、真機 VoiceOver／TalkBack、色覺或操作失誤率的驗收，以上仍待實際測試。
